## Probe mistakes worth keeping

- `text=Keep this hand` matched the prompt *sentence* ("Keep this hand?") before the
  button, so the first run never left pregame. Use `button:has-text(...)`.
- The `title`-ban gate (`test_frontend_card_elements_carry_no_native_title`) also requires
  the `use:cardTooltip` tag to show `caption` or `tooltipArg(` textually; a `$derived`
  argument hid it. Pass `{ name, caption }` inline.

## Dead end found by the long probe, and the rule that closes it

Turn 13, seed 3: Nadaar's dungeon room gave a scry — an `EffectChoice` decision whose only
real action is `AnswerEffectChoice` with **`object_id: 0`** (the redacted placeholder id; a
room is not a card, so `question_card_label` prints "(hidden card)"). No chip had id 0, so
nothing was lit, `looseActions` (which only took `object_id == null`) offered nothing, and
the panel said "Click a lit card." The old surface was immune because it rendered every
action as a button.

Rule now: an action is a button whenever its `object_id` is not among the ids the surface
**draws** (`renderedIds`: hand, all battlefields, command zones) — regardless of what the id
says. And a non-`Priority` decision with exactly one real answer opens its picker on arrival
(generalised from the declare-only rule). Server-side display gap worth a seed: a dungeon
room's question labels its source "(hidden card)".

## Second dead-ish affordance: an offer with no legal target

Turn 21: Swiftfoot Boots lit, its only action Equip with `target_min 1` and zero candidates
(no creature of yours). The picker shows "no legal target" + Back — correct, but a dead
click. `answerable(a)` now keeps such an action out of the lit set and the loose buttons.
The server-side offer itself is a `legal_actions` question, not touched here.

## Game over reached

Seed 3, greedy headless driver (each lit card tried once per decision, then pass / next
step): **game over at turn 57**, Bot-4 wins at 69 life, Human-1 at −8. Partition (scry),
cost, target, attacker and blocker pickers all exercised inside the prompt panel; no page
errors; every region rect identical across ~2,000 recorded transitions.
